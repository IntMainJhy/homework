# FDE 课堂作业3：人工复核意见记录与追溯

在作业2第一阶段基础上完成第二阶段：保存合成核对草稿，人工选择结构化意见，关联来源与规则指纹，刷新或服务重启后恢复完整历史。记录意见不批准培训、不关闭异常、不放行生产。

## 交付入口

## 技术栈与源码

严格沿用 Node.js ≥22、原生 JavaScript ESM、HTML/CSS/JavaScript、node:http、node:fs/promises、node:test、node:assert/strict，唯一第三方依赖仍为 yaml@2.9.1。使用原生 node:crypto 计算指纹和生成编号；持久记录采用本地 JSONL 文件，不使用数据库、模型或新中间件。

按照“基于现有项目迭代”的约束，代码继续位于 [作业2/src](../作业2/src)，不复制或另建第二套源码。作业3单独归档方案、接口与验收文件；作业1和仓库根 README 保持原样。

## 从仓库根目录运行

```sh
npm --prefix 作业2/src ci --ignore-scripts --no-audit --no-fund # 按锁文件恢复唯一依赖。
npm --prefix 作业2/src start # 打开 http://127.0.0.1:4180。
```

另一个终端执行：

```sh
npm --prefix 作业2/src test # 执行原有回归及第二阶段测试。
node 作业2/src/review-smoke.mjs # 直接验证意见提交、重试、重启恢复与日志故障。
node 作业2/src/verify.mjs 作业2/work-evidence/phase2 # 生成完整本地证据。
```

默认演示身份 operator；先运行核对，再点击“记录人工复核意见”，查看草稿、选择意见与原因，并手动勾选确认后保存。刷新页面后，在“人工复核记录”加载已保存草稿。

本地日志默认位于 `作业2/src/var/review-events.jsonl`，不上传 GitHub；测试使用独立临时目录，不删除或污染用户运行记录。演示身份可以自报，不是真实登录或正式签名。
