# 配置与合成数据字典

> 第一阶段文档归档：作业3已新增本地复核记录、配置和接口，当前说明见[作业3方案](../../../作业3/doc/人工复核记录与追溯方案.md)与[接口字典](../../../作业3/doc/接口与数据字典.md)。

## 配置入口与修改方式

唯一运行配置为 `作业2/src/config.yaml`，服务启动时读取，修改后重启生效；数据路径相对该配置文件解析，不依赖终端当前目录。配置缺失、YAML 格式错误、重复键、别名或关键字段不合法时停止启动，不使用隐藏默认值。

`package.json` 是 Node 包清单，`package-lock.json` 是依赖锁文件，均不是第二份业务运行配置。JSON 不支持注释，因此在本文件说明字段；源码与 YAML 的每行代码使用中文注释。

| 配置字段 | 默认值 | 校验与用途 |
|---|---|---|
| `server.host` | `127.0.0.1` | 仅允许该回环地址 |
| `server.port` | `4180` | 整数 1–65535；不再读取 PORT 环境变量 |
| `server.maxBodyBytes` | `16384` | 正安全整数；按请求体字节数限制内存缓存 |
| `server.requestTimeoutMs` | `10000` | 正安全整数；HTTP 请求接收超时，不是上游模型超时 |
| `project.projectId` | `fsg-production-handover` | 首版固定项目，不能用配置扩大范围 |
| `project.attemptId` | 原课堂练习编号 | 仅用于保留需求追溯信息 |
| `project.assignment` | `FDE课堂作业2` | 页面与证据说明 |
| `project.trainingHref` | 原平台相对链接 | 历史元数据，不触发网络请求 |
| `project.modules` | 当前项目的一个模块 | 包含 id、title、company；id 必须匹配项目 |
| `project.pipeline` | 原需求配置 | 包含 projectId、attemptId、requirements、solution、build、note；项目及练习编号必须一致 |
| `access.identity` | `operator` | 首版固定演示身份，不是真实登录 |
| `access.recordId` | `HND-DEMO-001` | 首版固定样本 |
| `data.fixturePath` | `data/handover.json` | 只允许 data 目录内简单文件名 JSON，并检查真实路径避免符号链接越界 |
| `rules.version` | `handover-rules-v3` | 非空规则版本，进入每份领域结果 |
| `rules.maxAgeMinutes` | `60` | 正整数；教学时效阈值，以合成核对时间计算 |
| `rules.maxRequestLength` | `2000` | 任务文字长度上限，单位为 JavaScript 字符串长度 |
| `rules.maxFieldLength` | `80` | 版本、接收人字段长度上限 |
| `rules.maxItems` | `20` | 检查项数组数量上限 |
| `rules.maxItemLength` | `40` | 单个检查项长度上限，且仍须满足合成编号格式 |

`pipeline.requirements` 中每条仅描述需求编号和内容；`solution` 与 `build` 保留 null，不能擅自改为客户确认或验收通过。

当前没有模型配置和任何密钥。未来获得授权接入模型时，地址仍须放在 YAML，密钥只通过环境变量注入，YAML 只写环境变量名称；第一阶段没有预先实现模型调用或秘密读取功能。

## 原始合成快照

`data/handover.json` 从旧 runtime fixture 分离，原岗位、版本、时间、清单及合成人员值保持不变；新增 synthetic 标识，原 maxAgeMinutes 阈值迁到 YAML。

| 字段 | 类型 | 含义 |
|---|---|---|
| `synthetic` | boolean | 必须为 true |
| `id` | string | 必须匹配配置允许的样本 |
| `job` / `process` / `batch` | string | 合成岗位、工序与批次编号，分别为 JOB-*、PROC-*、BATCH-DEMO-* |
| `instructionVersion` | string | 合成工序指引版本，如 v2 |
| `instructionState` | enum | confirmed、unconfirmed 或 missing |
| `validFrom` / `validTo` | string | 带时间信息的有效期，必须能解析且起点早于终点 |
| `trainingVersion` | string | 合成培训版本，空串表示缺版本 |
| `trainingState` | enum | confirmed、unconfirmed 或 missing，三者不可混同 |
| `requiredItems` | string[] | 不为空、不重复的合成必查项，如 C01、C02 |
| `completedItems` | string[] | 已记录的合成检查项 |
| `owner` | string | 固定为现场专员（演示） |
| `receiver` | string | 质量复核员（演示）或空值 |
| `exceptions` | object[] | 合成异常，每条为 id、status、owner 三字段；状态 open/closed |
| `sourceVersion` | string | 原始快照版本，如 snapshot-v2 |
| `capturedAt` | string | 原始采集时间，演示值为 2026-11-05 09:00 +08:00 |
| `reviewedAt` | string | 固定合成核对时间，演示值为 2026-11-05 09:05 +08:00 |

异常 id 使用 EX-DEMO-*，owner 必须匹配演示交出人。未知字段、结构错误或非合成来源降级，不将原文放入结果。日期无效、有效期倒置、快照晚于核对时间或超出时效时转人工。

来源文件不提供 HTTP 下载；通过授权核对接口返回的引用为原始快照。故障场景与表单值不写回该文件。

## 包清单与锁文件

`package.json`：name 为包名，version 为阶段版本，private 禁止误发布，type 指定 ESM，engines 指定 Node≥22，scripts 提供 start/test/verify/evidence 命令，dependencies 只包含精确版本 yaml。

`package-lock.json`：由 npm 自动生成，记录 lockfileVersion、包名版本、packages、精确下载位置和 integrity 校验值；保持合法 JSON，不手写注释，不手改依赖解析结果。锁文件中的 npm 地址仅用于开发安装，不是业务运行的外部请求。

## 导出与证据 JSON

浏览器下载使用统一接口外壳，仅含当前领域结果；不保存请求头、密钥、任务原文或人工签名。`sources[].snapshot` 为合成原始快照；`details` 为副本核对差异；`trace` 为规则处理轨迹。

验证证据包含生成时间、Node 环境、源码哈希、实际测试数量、五轮一致性评估、HTTP 验证摘要及未执行的真实活动。源码哈希仅覆盖列出的文件，修改源码后应重新生成证据。
