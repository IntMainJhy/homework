# 第一阶段接口契约

> 第一阶段文档归档：作业3已新增本地复核记录、配置和接口，当前说明见[作业3方案](../../../作业3/doc/人工复核记录与追溯方案.md)与[接口字典](../../../作业3/doc/接口与数据字典.md)。

默认服务地址为 http://127.0.0.1:4180，由 YAML 的 host、port 决定。业务接口不接受查询参数，不支持跨站调用，不提供 CORS 放开配置。

所有业务请求使用 `X-Demo-Identity: operator` 演示头。POST 还要求任务 identity 为 operator，两者必须一致；它们都是客户端可自报值，只适用于合成原型。服务端检查固定范围，不能据此声称已经实现真实身份认证。

## 统一响应及判定顺序

| 情况 | HTTP | ok | data | error |
|---|---|---|---|---|
| 正常处理业务核对 | 200 | true | 业务结果，状态在 status | code 与 msg 均为空串 |
| 已处理但业务需转人工或被规则拒绝 | 200 | true | manual、needs-info、blocked 或 degraded 结果 | code 与 msg 均为空串 |
| HTTP 输入错误、身份拒绝或范围拒绝 | 4xx | false | null | 明确错误码和中文信息 |
| 状态初始化来源不可用 | 503 | false | null | SOURCE_UNAVAILABLE |
| 未预期内部错误 | 500 | false | null | INTERNAL_ERROR，不带内部异常 |

先检查 HTTP 状态及 ok，再读取 data.status；不得将 ok=true 当成业务批准。被拒请求没有读取来源，因此错误外壳不携带来源位置、版本、快照或记录原文。

## GET /api/state

授权后读取合成样本，返回页面所需字段：projectId、assignment、modules、ruleVersion、maxAgeMinutes、limits、product、scenarios。

product 包含名称、边界、三个处理节点和表单 defaults。不会返回完整 YAML、服务参数或环境变量。默认页面未执行核对，显示“尚未运行”，不预填成功结论。

## POST /api/run

顶层只接受 projectId 和 input。projectId 为指定项目字符串，input 为对象；顶层缺字段、类型错误或未知字段属于 HTTP 输入错误。

| input 字段 | 规则 |
|---|---|
| `identity` | 必须显式为 operator，且与请求头一致 |
| `moduleId` | 可省略；提供时必须匹配固定项目，空串也拒绝 |
| `recordId` | 可省略；提供时必须为 HND-DEMO-001，空串也拒绝 |
| `mode` | 可省略，提供时只接受 offline |
| `scenario` | 可省略为 normal，只接受下述枚举 |
| `request` | 可省略；提供时为非空字符串，长度不超过配置上限；原文不进入结果 |
| `trainingVersion` | 可省略使用来源；提供时为 v 加 1–6 位数字，或空白值以演练缺失 |
| `trainingState` | 可省略使用来源；提供时仅 confirmed/unconfirmed/missing |
| `completedItems` | 可省略使用来源；提供时为配置限额内字符串数组，每项为 C 加 2–4 位数字 |
| `receiver` | 可省略使用来源；仅质量复核员（演示）或空白值，不接收真实姓名 |

input 未知字段、非法类型、在线模式或越界自然语言由规则返回 `blocked`，且不读取来源。模块、记录、项目或 HTTP 身份越权则在规则执行前返回 HTTP 403。

scenario 枚举：normal、missing、conflict、unconfirmed、missing-item、open-exception、invalid-rule、stale、unauthorized、outage、injection。场景仅注入合成副本，不能变更原始 JSON。

### 领域结果字段

| 字段 | 含义 |
|---|---|
| `projectId` / `moduleId` / `recordId` | 固定教学范围 |
| `status` | review、needs-info、manual、blocked、degraded |
| `title` / `summary` / `details` | 中文结论及差异，不能作为正式批准 |
| `sources` | 原始合成来源清单，拒绝或来源故障时为空 |
| `sources[].location/version/capturedAt` | 来源位置、版本与采集时间 |
| `sources[].snapshot/excerpt` | 原始合成快照，不混入表单覆盖 |
| `trace` | step、agent、action、detail 组成的处理轨迹 |
| `ruleVersion` / `mode` / `synthetic` | 规则版本、offline-fixture、true |
| `writes` / `externalSends` | 固定为 0 |
| `approval` / `reviewStatus` | 未获人工批准、pending |
| `reviewOwner` | 建议人工责任角色，尚待具名授权 |

正常样本 status=review；缺培训、版本、接收人或检查项为 needs-info；版本冲突、未确认、过期、无效时间或未结异常为 manual；来源不可用为 degraded。

## POST /api/evaluate

同样使用 projectId、input，input 只接受 identity、moduleId、recordId。返回 mode、ruleVersion、total、passed、cases；实际执行原有 17 个合成场景，不使用历史预填统计。内部拒绝场景用于验证边界，不扩大调用者权限。

## 错误码

| 错误码 | HTTP | 典型触发 |
|---|---|---|
| FORBIDDEN | 403 | 演示头缺失、不是 operator 或与任务身份不一致 |
| SCOPE_FORBIDDEN | 403 | 跨项目、模块、记录，或提供空范围 |
| ORIGIN_FORBIDDEN | 403 | Host 或 Origin 不属于当前回环服务 |
| INVALID_JSON | 400 | JSON 语法错误、null 或数组 |
| INVALID_INPUT | 400 | 缺少 projectId/input 或类型错误 |
| UNKNOWN_FIELD | 400 | 顶层未知字段，或评估 input 扩展字段 |
| UNKNOWN_QUERY | 400 | 接口携带未定义查询参数 |
| PAYLOAD_TOO_LARGE | 413 | 请求字节数超过 YAML 限额 |
| UNSUPPORTED_MEDIA_TYPE | 415 | POST 不是 application/json |
| METHOD_NOT_ALLOWED | 405 | 方法不符合接口契约 |
| NOT_FOUND | 404 | 未定义路径或私有文件路径 |
| SOURCE_UNAVAILABLE | 503 | 状态初始化无法读取有效合成来源 |
| INTERNAL_ERROR | 500 | 未预期服务故障 |
| BAD_HTTP_REQUEST | 400 | HTTP 协议解析错误 |

## 静态资源与人工复核边界

仅 GET/HEAD `/`、`/index.html`、`/app.js`、`/style.css` 返回正常资源格式；配置、数据、服务端源码和旧 `/project.json` 不公开。

第一阶段没有人工意见提交、审批、业务写回、设备控制、消息发送接口。页面只展示待人工复核状态，不能把导出当成签字。接口没有持久会话、访问审计或真实登录系统。
