## 启动与验证

从仓库根目录执行：

```sh
npm --prefix 作业2/src ci --ignore-scripts --no-audit --no-fund # 安装锁定依赖。
npm --prefix 作业2/src start # 启动本机工作台。
```

另一个终端执行：

```sh
npm --prefix 作业2/src test # 运行自动测试。
node 作业2/src/smoke.mjs # 可直接运行的完整验证脚本，无需等待已有服务。
node 作业2/src/verify.mjs 作业2/work-evidence/phase1 # 生成可复核证据。
```

## 主要风险及阶段限制

1. **演示身份可自报**：白名单和范围检查已经在服务端执行，但没有真实登录和身份凭证；只可用于本机合成原型。
2. **时间为历史演练**：固定 reviewedAt 保证复现，60 分钟仅为教学假设，不能证明当前生产资料有效。
3. **没有人工意见审计链**：当前只展示 pending；不保存复核意见、正式签字或审批关系，下载不等于批准。
4. **来源只覆盖固定样本**：新字段、新版本格式和真实人员会被拒绝；不支持多记录关联、真实数据导入或生产异常处理。
5. **配置及本机文件可被本机用户修改**：运行前需检查配置与合成来源，变更后重新测试；没有签名、持久审计和生产权限隔离。
6. **无持久历史**：刷新会清空界面结果，用户需先导出；导出不包含自由任务原文。

下一阶段应先确认是否继续建设人工意见的记录契约及其权限边界，不自行增加审批、模型或真实系统接入。
